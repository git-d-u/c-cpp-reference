## 4.1 配列

```c
int a[5];                       // 要素数 5（自動変数なら値は不定）
int b[5] = {1, 2, 3};           // 残りは 0 で初期化 => {1,2,3,0,0}
int c[]  = {1, 2, 3};           // 要素数は初期化子から決定 (3)
int d[5] = {0};                 // すべて 0
int e[5] = {[2] = 10, [4] = 20};// 指示付き初期化子 (C99)

size_t len = sizeof(c) / sizeof(c[0]);  // 要素数 => 3
```

- 添字は `0` から `要素数-1` まで。範囲外アクセスは**未定義動作**（チェックされない）。
- 配列同士の代入 (`a = b;`) はできない。`memcpy` を使う。

### 多次元配列

```c
int m[2][3] = {
    {1, 2, 3},
    {4, 5, 6},
};
m[1][2];   // => 6
```

メモリ上は行優先（row-major）で連続して配置される。

### 可変長配列 (VLA)

```c
void f(int n)
{
    int arr[n];   // C99 で導入、C11 以降はオプション機能
}
```

MSVC は VLA をサポートしていない。

## 4.2 ポインタの基本

```c
int x = 10;
int *p = &x;    // & : アドレス演算子。p は x のアドレスを保持
*p = 20;        // * : 間接参照演算子。x が 20 になる

int *q = NULL;  // どこも指さないポインタ（NULL は <stddef.h> 等で定義）
if (q != NULL) { /* 使用前にチェック */ }
```

| 記法 | 意味 |
|------|------|
| `int *p` | int へのポインタ |
| `&x` | x のアドレス |
| `*p` | p が指す先の値 |
| `p->m` | `(*p).m` と同じ（構造体メンバ） |

## 4.3 ポインタと配列の関係

```c
int a[] = {10, 20, 30};
int *p = a;        // 配列名は（多くの文脈で）先頭要素へのポインタに変換される

*(p + 1);          // => 20
p[2];              // => 30  （p[i] は *(p + i) と同じ）
p++;               // 次の要素へ（int のサイズ分アドレスが進む）
```

- **ポインタ演算**: `p + n` は `n * sizeof(*p)` バイト先を指す。
- ポインタ同士の差は `ptrdiff_t` 型（`<stddef.h>`）。
- `sizeof(a)` は配列全体のサイズ、`sizeof(p)` はポインタのサイズ（配列はポインタではない）。

## 4.4 const とポインタ

```c
const int *p1;        // 指す先の値を変更できない（p1 自体は変更可）
int const *p2;        // 上と同じ
int *const p3 = &x;   // p3 自体を変更できない（指す先の値は変更可）
const int *const p4 = &x;  // どちらも変更不可
```

> 読み方のコツ: `*` の左にある `const` は「指す先」、右にある `const` は「ポインタ自身」を修飾する。

## 4.5 ポインタのポインタ

```c
int x = 1;
int *p = &x;
int **pp = &p;
**pp = 5;    // x が 5 になる
```

## 4.6 void ポインタ

```c
void *vp = &x;          // 任意の型のポインタを代入できる
int *ip = vp;           // C では暗黙変換可能（C++ ではキャストが必要）
```

- `void *` は間接参照もポインタ演算もできない（GCC は拡張でポインタ演算を許可）。

## 4.7 文字列

C の文字列は**末尾がヌル文字 `'\0'` の `char` 配列**。

```c
char s1[] = "hello";       // 要素数 6 ('\0' を含む)。変更可能
char s2[10] = "hi";        // 残りは '\0'
const char *s3 = "world";  // 文字列リテラルを指す。変更は未定義動作

s1[0] = 'H';               // OK => "Hello"
// s3[0] = 'W';            // NG: 未定義動作
```

文字列操作関数は [標準ライブラリ: string.h](07-stdlib.md#73-stringh--文字列メモリ操作) を参照。

### 文字列の配列

```c
const char *names[] = { "Alice", "Bob", "Carol" };
for (size_t i = 0; i < 3; i++)
    printf("%s\n", names[i]);
```

## 4.8 よくある誤り

| 誤り | 内容 |
|------|------|
| 未初期化ポインタの使用 | `int *p; *p = 1;` は未定義動作 |
| ダングリングポインタ | 解放済み・寿命切れの領域を指すポインタの使用 |
| ローカル変数のアドレスを返す | 関数終了後、その領域は無効 |
| バッファオーバーフロー | 配列の範囲外への書き込み |
| `'\0'` の分を確保し忘れる | `strlen(s) + 1` バイト必要 |

```c
int *bad(void)
{
    int local = 10;
    return &local;   // NG: 関数終了後に無効になる
}
```
