## 1.1 最小のプログラム

```c
#include <stdio.h>   // 標準入出力ヘッダ

int main(void)       // プログラムの開始点
{
    printf("Hello, World!\n");
    return 0;        // 0 は正常終了を表す
}
```

- `main` の戻り値は `int`。`return 0;`（または `EXIT_SUCCESS`）で正常終了。
- C99 以降、`main` の末尾で `return` を省略すると `return 0;` とみなされる。
- コマンドライン引数を受け取る形: `int main(int argc, char *argv[])`

## 1.3 基本データ型

| 型 | 典型的なサイズ※ | 規格上の最低保証 | 用途 |
|----|----------------|------------------|------|
| `char` | 1 バイト | 8 ビット以上 | 文字・最小単位 |
| `short` | 2 バイト | 16 ビット以上 | 小さな整数 |
| `int` | 4 バイト | 16 ビット以上 | 標準的な整数 |
| `long` | 4 または 8 バイト | 32 ビット以上 | 大きな整数 |
| `long long` | 8 バイト | 64 ビット以上 | さらに大きな整数（C99） |
| `float` | 4 バイト | — | 単精度浮動小数点 |
| `double` | 8 バイト | — | 倍精度浮動小数点 |
| `long double` | 8〜16 バイト | — | 拡張精度浮動小数点 |
| `_Bool` | 1 バイト | — | 真偽値（C99、`<stdbool.h>` で `bool`） |

※ サイズは処理系依存。`sizeof(char)` だけは常に 1。`long` は Windows (64bit) では 4 バイト、Linux (64bit) では 8 バイトが一般的。

### 符号の有無

```c
signed int   a = -10;   // 符号付き（int はデフォルトで符号付き）
unsigned int b = 10u;   // 符号なし（負の値を持てない）
```

- `char` が符号付きか符号なしかは**処理系定義**。

### 固定幅整数型（`<stdint.h>`、C99）

```c
#include <stdint.h>

int8_t   i8;   uint8_t  u8;
int16_t  i16;  uint16_t u16;
int32_t  i32;  uint32_t u32;
int64_t  i64;  uint64_t u64;
size_t   n;    // sizeof の結果の型（<stddef.h> などで定義）
intptr_t p;    // ポインタを保持できる整数型（オプション）
```

サイズを厳密に扱いたい場合は固定幅整数型を使う。

## 1.4 変数の宣言と初期化

```c
int x;              // 宣言（自動変数は初期化しないと値は不定）
int y = 10;         // 宣言と初期化
int a = 1, b = 2;   // 複数同時
double pi = 3.14159;
char c = 'A';       // 文字定数はシングルクォート
```

- 関数内の自動変数は**初期化しないと不定値**。読み出すと未定義動作になり得る。
- グローバル変数・`static` 変数は**自動的に 0 で初期化**される。

## 1.7 演算子

### 算術演算子

| 演算子 | 意味 | 例 |
|--------|------|-----|
| `+` `-` `*` `/` | 四則演算 | `7 / 2` → `3`（整数同士は切り捨て） |
| `%` | 剰余 | `7 % 2` → `1` |
| `++` `--` | インクリメント/デクリメント | `i++`（後置）、`++i`（前置） |

- 整数の除算はゼロ方向への切り捨て（C99 以降で規定）。
- 0 による整数除算は未定義動作。
- 符号付き整数のオーバーフローは未定義動作。符号なし整数はラップアラウンドする。

### 比較・論理演算子

| 演算子 | 意味 |
|--------|------|
| `==` `!=` | 等しい / 等しくない |
| `<` `>` `<=` `>=` | 大小比較 |
| `&&` `\|\|` `!` | 論理 AND / OR / NOT（短絡評価） |

C では比較結果は `int` 型の `1`（真）または `0`（偽）。0 以外はすべて真として扱われる。

### ビット演算子

| 演算子 | 意味 | 例（`a = 0b1100`, `b = 0b1010`） |
|--------|------|------|
| `&` | AND | `a & b` → `0b1000` |
| `\|` | OR | `a \| b` → `0b1110` |
| `^` | XOR | `a ^ b` → `0b0110` |
| `~` | NOT（反転） | `~a` |
| `<<` | 左シフト | `1 << 3` → `8` |
| `>>` | 右シフト | `16 >> 2` → `4` |

※ `0b` 表記は C23 から標準。それ以前は GCC/Clang の拡張。

### 代入演算子

```c
x = 5;
x += 3;   // x = x + 3
x -= 3;  x *= 3;  x /= 3;  x %= 3;
x &= 1;  x |= 1;  x ^= 1;  x <<= 1;  x >>= 1;
```

### その他

```c
int max = (a > b) ? a : b;   // 条件演算子（三項演算子）
size_t s = sizeof(int);      // サイズ取得（バイト数）
double d = (double)7 / 2;    // キャスト => 3.5
int r = (a = 1, b = 2);      // カンマ演算子（右辺の値 => 2）
```

### 演算子の優先順位（高い順・抜粋）

| 優先度 | 演算子 | 結合 |
|--------|--------|------|
| 1 | `()` `[]` `->` `.` 後置`++` `--` | 左→右 |
| 2 | 前置`++` `--` 単項`+` `-` `!` `~` `*`(間接) `&`(アドレス) `sizeof` キャスト | 右→左 |
| 3 | `*` `/` `%` | 左→右 |
| 4 | `+` `-` | 左→右 |
| 5 | `<<` `>>` | 左→右 |
| 6 | `<` `<=` `>` `>=` | 左→右 |
| 7 | `==` `!=` | 左→右 |
| 8 | `&` | 左→右 |
| 9 | `^` | 左→右 |
| 10 | `\|` | 左→右 |
| 11 | `&&` | 左→右 |
| 12 | `\|\|` | 左→右 |
| 13 | `?:` | 右→左 |
| 14 | `=` `+=` `-=` など | 右→左 |
| 15 | `,` | 左→右 |

> 迷ったら括弧を付けるのが安全。特に `&` と `==` の組み合わせ（`x & 1 == 0` は `x & (1 == 0)` と解釈される）に注意。

## 1.8 型変換

- **暗黙の型変換**: 演算時、より大きな型へ揃えられる（通常の算術変換）。`int` より小さい型は `int` に昇格される（整数拡張）。
- **符号付きと符号なしの混在に注意**:

```c
int a = -1;
unsigned int b = 1;
if (a < b) { /* ... */ }  // a が unsigned に変換され、大きな値となるため偽になる
```
