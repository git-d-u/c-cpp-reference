## 得意分野診断

**[得意分野診断を開く](shindan/index.html){ .md-button .md-button--primary }**

- 8分野の一問一答です。1日30問ずつ解いて採点し、分野別の正答率から得意・不得意を確かめます。
- 答えは単語か記号で入力します。登録してある別解と照らし合わせて自動で採点します。言い回しが違うだけで内容が合っているときは、各問の「正解にする」で直せます。
- 回答と採点結果は、使っているブラウザの中にだけ保存されます（スマホとパソコンでは別々です）。

| 分野 | 主な内容 |
|------|---------|
| Webセキュリティ | XSS、CSRF、SQLインジェクション、パストラバーサル、Cookie の属性 |
| ネットワーク・DNS | ファイアウォール、プロキシ、DNS のしくみと攻撃 |
| 認証・暗号 | パスワードの保存、多要素認証、PKI、デジタル署名、TLS |
| マルウェア・インシデント対応 | 侵入の手口、C&C、ログの調査、初動対応 |
| クラウド・ゼロトラスト | クラウドの設定、アクセス制御、ゼロトラスト |
| セキュア開発 | 安全なコーディング、脆弱性の診断 |
| 組織・管理・法令 | リスクアセスメント、規程、委託先の管理 |
| メール・無線・IoT/OT | 送信ドメイン認証、無線 LAN、制御システム |

## 出典について

- 問題は、IPA が公表している情報処理安全確保支援士試験の過去問題（午後Ⅰ・午後Ⅱ・午後）をもとにした一問一答と、オリジナルの問題です。各問の下に出典を記載しています。
- 過去問題をもとにした問題は、一問一答の形に改変しています。元の問題と解答例は [IPA の過去問題のページ](https://www.ipa.go.jp/shiken/mondai-kaiotu/index.html) で確認できます。
- 市販の問題集の文章は使っていません。

## 問題の追加のしかた（管理用）

問題データは `docs/sc/shindan/questions.json` の1ファイルです。追加すると、アプリの日のタブと問題数は自動で増えます。

1. `questions` に1問を1行で追記する（ID は `D日-番号`、例：`D5-01`）
2. ローカルで検査する：`node tools/validate_shindan.js docs/sc/shindan/questions.json`
3. push すると、GitHub Actions が同じ検査をしてから公開する（エラーがあれば公開されない）

| 項目 | 内容 |
|------|------|
| `id` / `day` / `no` | ID、何日目か、その日の何問目か |
| `f` | 分野（`web` `nw` `auth` `ir` `cloud` `dev` `mgmt` `misc`） |
| `q` | 問題文 |
| `c` | 選択肢の配列（記号選択のとき）。記述のときは `null` |
| `a` | 正解（記号選択はア〜エ） |
| `acc` | 記述のとき、正解として認める答えの一覧 |
| `disp` | 採点後に表示する正解 |
| `ex` | 解説 |
| `src` | 出典（`R6春 午後 問1 設問2 をもとに作成` または `オリジナル`） |
